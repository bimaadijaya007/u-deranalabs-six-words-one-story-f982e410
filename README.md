# Six Words, One Story

One complete story in exactly six words, written by `main.ts` to `/output/entry.txt`:

> She kept his letters. Burned mine.

The program is deterministic: it writes the same story on every run
(Node 22, `node:fs` only, no network, no input).

Run: `node main.ts`
